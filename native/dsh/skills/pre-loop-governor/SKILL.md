# Pre-loop governor

Discuss the intended user, outcome, existing stack, Component–Module–Product tree, every execution step, acceptance mode, visible checks, unattended behavior, permissions, failure handling, and delivery boundary. Infer likely intent and confirm it in beginner-friendly language, one decision area at a time. Keep one living document as the sole authority. Do not implement until the independent gate passes and the user submits the exact native start command.
