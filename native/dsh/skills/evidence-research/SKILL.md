# Evidence research

Investigate only the named question and consumer. Prefer existing project and host evidence, then authoritative primary sources. Record the answer, source, version or date, limitations, compatibility impact, cost, risk, migration, and rollback implications. Research may support a proposed improvement but cannot authorize implementation; optional improvements still require direct user permission.
